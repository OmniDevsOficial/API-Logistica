## 📘 Manual do Usuário

### 1. Introdução

Uma `Plataforma de Controle de Motoristas Agregados`, desenvolvida para auxiliar no acompanhamento de viagens, disponibilidade e desempenho financeiro dos motoristas. O sistema reúne informações operacionais para apoiar a análise e a tomada de decisões da transportadora.

### 2. Objetivo do sistema

A plataforma tem como objetivo facilitar a visualização dos dados dos motoristas agregados, permitindo acompanhar indicadores de utilização, consultar informações sobre viagens e analisar a rentabilidade das operações, conforme as funcionalidades disponibilizadas na versão instalada.

### 3. Acessando a aplicação

1. Verifique se a aplicação foi instalada e iniciada conforme o Manual de Instalação.
2. Abra um navegador de internet.
3. Acesse o endereço da interface web informado pela equipe responsável pela instalação. No ambiente local padrão, o endereço é `http://localhost:3000`.
4. Aguarde o carregamento da interface.

Caso a página não abra, confirme se os serviços estão em execução e consulte o Manual de Instalação.

### 4. Conhecendo a plataforma

A plataforma utiliza dados operacionais para apresentar informações relacionadas aos motoristas agregados e às viagens. As opções disponíveis podem variar conforme a versão instalada e as funcionalidades implementadas.

Utilize os menus, filtros e campos apresentados na interface para acessar as informações disponíveis.

### 5. Importação de dados

Quando a funcionalidade estiver disponível, utilize a opção de importação correspondente ao tipo de arquivo solicitado pela aplicação.

1. Localize a funcionalidade de importação.
2. Selecione o arquivo no formato aceito pelo sistema.
3. Confira se o arquivo corresponde ao tipo de informação solicitado.
4. Execute a importação conforme as instruções exibidas na interface.
5. Verifique a mensagem apresentada e confira se os dados foram processados corretamente.

Importe apenas arquivos compatíveis com o formato esperado pelo sistema. Em caso de erro, confira o arquivo e as orientações apresentadas na tela.

### 6. Consulta e análise de viagens

Se disponível na versão instalada, utilize os recursos de consulta para visualizar as viagens registradas no sistema.

Os filtros apresentados na interface podem permitir a seleção de informações por destino ou região, facilitando a análise da demanda por rota.

Após aplicar um filtro, confira os resultados exibidos e remova ou altere os critérios de pesquisa para consultar outros dados.

### 7. Acompanhamento dos motoristas

A plataforma tem como objetivo apoiar o acompanhamento dos motoristas agregados. Conforme as funcionalidades implementadas, podem estar disponíveis indicadores como:

- Quantidade de viagens realizadas em determinado período.
- Percentual de utilização dos motoristas.
- Disponibilidade para novas operações.
- Valores recebidos e custos associados às viagens.
- Rentabilidade média por viagem.

Utilize os indicadores como apoio à análise operacional e confira o período e os filtros selecionados antes de comparar resultados.

### 8. Consulta de relatórios

Caso a versão instalada disponibilize recursos de relatórios, acesse a área correspondente e selecione os critérios de consulta disponíveis.

Confira os dados apresentados antes de utilizar os resultados em análises ou decisões operacionais.

### 9. Exportação de dados

Se a funcionalidade estiver disponível, utilize a opção de exportação apresentada pela aplicação para gerar o arquivo de análise.

Após a exportação, verifique se o arquivo foi salvo no local esperado e se contém os dados desejados.

### 10. Boas práticas de utilização

- Utilize arquivos de origem confiável e no formato aceito pela aplicação.
- Confira os dados importados antes de utilizá-los em análises.
- Verifique os filtros e o período selecionado ao comparar indicadores.
- Evite compartilhar arquivos que contenham informações operacionais ou pessoais com pessoas não autorizadas.
- Em caso de comportamento inesperado, registre a mensagem exibida e informe a equipe responsável.

### 11. Solução de problemas

**A aplicação não abre:** confirme se os serviços foram iniciados e se o endereço de acesso está correto.

**A importação falha:** confira o formato do arquivo, os campos obrigatórios e a mensagem de erro apresentada.

**Os dados esperados não aparecem:** verifique os filtros selecionados e confirme se os dados foram importados ou registrados corretamente.

**A aplicação apresenta um erro inesperado:** anote a operação realizada e a mensagem exibida e entre em contato com a equipe responsável pelo sistema.

Para problemas relacionados à instalação, consulte o Manual de Instalação.

### 12. Considerações finais

Este manual orienta a utilização da plataforma `Plataforma de Controle de Motoristas Agregados`. As instruções devem ser atualizadas conforme as funcionalidades efetivamente disponibilizadas na versão entregue ao cliente.
